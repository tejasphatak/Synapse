The Vision

Every phone has a GPU sitting idle. Every laptop, every tablet. Billions of GPUs, unused.

Synapse splits transformer models across multiple browser devices — coordinated over WebSockets, computed entirely on-device via WebGPU. A classroom of 30 Chromebooks can collectively run a language model. A family's phones at dinner can be a GPU cluster.

No cloud GPUs. No API keys. No cost per token. Just browsers.

How It Works

Coordinator (Node.js) | binary SYN1 protocol (int8 quantized) / \ Device A Device B WebGPU WebGPU Layers 0-5 Layers 6-11 (any GPU) (any GPU) \ / token output | streaming response

Split any HuggingFace model into N shards. Each browser loads one shard and runs WebGPU compute. The coordinator routes activations between nodes and manages the autoregressive generation loop.

Try It

git clone https://github.com/tejasphatak/Synapse.git cd Synapse/synapse-src && npm install python3 model/split.py --model gpt2 --dtype float16 --num-shards 2 node coordinator/index.js # Open two tabs at localhost:8080/node/index.html # Both show "Ready" → type in the chat → tokens stream

No GPU server needed. Two browser tabs on any WebGPU-capable laptop. That's it.
